{% comment %} Collection Map — an OpenStreetMap of the site's own pages Draws a marker for every page whose front matter carries `geo: [lat, lng]` and builds each popup out of that page's own fields, so a page joins the map by gaining coordinates and leaves it by losing them. Nothing is listed twice. This is not the historic-map component. A scanned map laid over real coordinates, with routes drawn on it, is `maps/figure-map.html`. Example: {% raw %}{% include nav/map.html folder="objects" fields="object-date,medium,collection" class="map-wrap--wide" height="70vh" %}{% endraw %} What goes on the map: - folder: map only the pages under this folder, e.g. "objects" (optional; the default is every page on the site with geo) - fields: comma-separated front matter fields printed in the popup beneath the place name, e.g. "object-date,medium,collection". A page missing one of them prints the rest. - image-field: front matter field holding the popup image (optional; default thumbnail, falling back to header-image) How it looks: - id: unique id, needed only if one page holds two maps (default: map) - height: CSS height (default: 700px) - width: CSS width (default: 100%) - class: extra classes on the map's wrapper. Pass class="map-wrap--wide" to break out of the text column. - start-coords: "[lat, lng]" opening centre (optional; by default the map opens on the view that fits every marker) - zoom: opening zoom level, 1–18. With start-coords it is the opening zoom; without it, the closest the automatic fit may go (default: 8). Each page contributes title and geo, and may add placename, summary, thumbnail or header-image, alt-text, and anything named in fields. start_coords, with an underscore, is still read for pages
