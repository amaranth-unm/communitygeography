{% comment %} Background Switch — changes the background of an open bg-multi-long section Drop one of these between passages of text. When the reader scrolls it past the middle of the screen, the section's background image becomes this one. Chain as many as the narrative needs. Parameters: - bg-id: the id given to the bg-multi-long section this belongs to (required) - switch-id: a unique id for this switch (required) - image-path: the image to switch to (required) The marker itself is not visible; it only marks a position in the text. {% endcomment %} {% capture image-path %} {% include helpers/image-path.html image-path=include.image-path %} {% endcapture %} {% assign image-path = image-path | strip %} {%- comment -%} height: 1px is load-bearing, not decoration. IntersectionObserver reports nothing for a zero-area target, and this marker has no content, so without a height it never intersects and the background never changes. One pixel in the flow of the text is invisible and is enough to be observed. {%- endcomment -%}
