{% comment %} Profile Intro — a photograph beside a name, a short bio, and a set of links. The opening block of a personal or portfolio homepage. It says who you are once, at full width, and then gets out of the way so the rest of the page can use the whole column. This is the successor to the profile sidebar (`layout: nav-profile`). The sidebar puts the same material in a permanent left rail, which costs a column on every page and, on a phone, stacks above the content anyway. Reach for the sidebar when a reader genuinely needs your links present on every page; reach for this when they need them once, on the way in. Reads `_data/nav-profile.yml` by default, so a site already using the sidebar can switch without touching its data. Parameters: - profile: an object to use instead of site.data.nav-profile (optional) - shape: rounded | circle — the photograph's frame (default: rounded) - width: content | wide — content lines the block up with the page's text column (default); wide matches the other landing bands, for a homepage built by stacking them - level: 1 | 2 — heading level for the name (default: 1). Use 2 on a page that already has an h1, such as one with a page-header. Data (_data/nav-profile.yml): image_url: /assets/images/profile/headshot.jpg alt_text: A photograph of Your Name name: Your Name role: Associate Professor of History # optional description: One or two sentences.
